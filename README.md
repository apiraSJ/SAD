# ระบบแจ้งซ่อมอาคารนอน นักเรียนนายเรืออากาศ

รายวิชา การวิเคราะห์และออกแบบระบบ (CS 334)

## สมาชิก

- นนอ.อภิรักษ์ สาจันทร์
- นนอ.กฤตเมธ จันทสุด
- นนอ.ธัญศิษฏ์ ศักดิ์ชัยศรี

## คำอธิบายโครงการ

ระบบแจ้งซ่อมอาคารนอนสำหรับนักเรียนนายเรืออากาศ
ใช้สำหรับแจ้งปัญหา-ความชำรุดภายในอาคารนอน ติดตามสถานะการซ่อม มอบหมายช่าง
บันทึกผลการซ่อมและค่าใช้จ่าย พร้อมสรุปรายงานสำหรับผู้บริหาร

## Prototype

Interactive Prototype (Web Application, Mobile-first, Responsive) สำหรับแสดง
กระบวนการทำงานของระบบตั้งแต่แจ้งซ่อมจนถึงปิดงาน โดยข้อมูลทั้งหมดเป็น Mock Data
บน `localStorage` (ไม่มีการเชื่อมต่อ Backend จริง)

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วย Web Browser (Chrome / Edge / Firefox รุ่นใหม่)

## Roles

- **นักเรียนนายเรืออากาศ (Cadet)** — แจ้งซ่อม, ติดตามสถานะของตนเอง, ดูผลการซ่อมและค่าใช้จ่าย
- **ผู้ดูแลอาคาร (Admin)** — ตรวจสอบคำขอ, รับเรื่อง, มอบหมายช่าง
- **ช่าง (Technician)** — รับงาน, เริ่มดำเนินการ, บันทึกผลการซ่อมและค่าใช้จ่าย, ปิดงาน
- **ผู้บริหาร (Executive)** — ดูภาพรวม, สถิติงาน, สรุปค่าใช้จ่าย

## Workflow

```
Login
→ แจ้งซ่อม
→ รอตรวจสอบ
→ รับเรื่อง
→ มอบหมายช่าง
→ ดำเนินการซ่อม
→ บันทึกผลและค่าใช้จ่าย
→ ซ่อมเสร็จ
→ ติดตามสถานะ / รายงาน
```
